04 · Design language

Content first. Borders over shadows. One accent.

A hierarchical, content-first interface influenced by Linear, Stripe, and Apple's Liquid Glass principles — explicitly not glassmorphism. Hierarchy comes from position, scale, spacing, and typography before it ever comes from decoration.

01

Two-layer interface model

Content layer dominates. UI/navigation floats. Transparency must be functional — every translucent surface answers “why should you see through this?”

02

No glass-on-glass (hard rule)

Nested glass surfaces produce mud. Elements sitting on glass get solid fills, typography, and spacing — never another blur layer.

03

Single accent, four-step surface hierarchy

bg < sunken < paper < elev in light; sunken < bg < paper < elev in dark. void and accent stay fixed across themes on purpose.

04

Motion demonstrates, never decorates

The Knowledge Orbit tilts a few degrees toward your cursor — it does not auto-rotate. Continuous motion is exactly what prefers-reduced-motion users opt out of.

05

Typography does the hierarchy work

Display → page title → section → primary → secondary → metadata. Size, weight, and contrast — not borders and shadows — carry the structure.

05 · Engineering

The stack, without the buzzwords.

Next.js 15 App Router, React 19, TypeScript, Tailwind, Supabase, and Gemini — chosen because each one removes a category of problem rather than adding a category of config.

Framework

Next.js 15 + React 19

App Router, Server Components, Turbopack dev, route groups for chrome-free auth pages.

Data

Supabase

Postgres, Auth, Storage. 20 tables, full RLS policies, versioned schema files.

Intelligence

Gemini API

Live product data, shopping recommendations, PC builds, admin draft generation.

Styling

Tailwind CSS

CSS-variable theme tokens, self-hosted variable fonts, zero runtime Google Fonts requests.

Auth

Two systems, on purpose

Admin: custom JWT cookie. Readers: Supabase Auth + RLS. Different trust boundaries, different mechanisms.

Content

Markdown pipeline

react-markdown + remark-gfm + rehype-highlight + rehype-slug, plus a custom figure-highlight plugin.

Performance

Guardrails, not guesses

Shared withTimeout on every Supabase call in the critical path. 2.5s cap — a broken config can't take every page to 7.4s.

Deploy

Vercel

Speed Insights + Analytics. Edge middleware for session refresh. npm run build from clean .next.

07 · FAQ

Straight answers.

The questions people actually ask.

Is this a public blog or a private one?

Private by default. It's a personal publication — your content, your rules. No ads, no trackers, no engagement bait; posts go public only when you choose.

Do I need a database to run it?

No. The site loads immediately with real sample content. Supabase only kicks in for accounts, saved libraries, and creator tools when you're ready for them.

What does it cost?

Reading and exploring are free. If the project saves you time, a Ko-fi tip keeps it alive — no subscriptions, no paywalls.

How is it funded?

No ads and no trackers. Ko-fi support covers hosting and coffee — that's the whole business model.

What's under the hood?

Next.js 15, React 19, Supabase, and Tailwind, deployed on Vercel with edge middleware and a hand-tuned design system in both themes.
