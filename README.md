# tech-site

### https://tech-site-new.vercel.app/

A multi-niche technology publication with a split publishing model: one admin account with full control and an AI drafting tool, and open signup for regular users who write and publish manually — no AI access on that side. Built on Next.js 15 (App Router) + Supabase, styled distinctly rather than with default templates. Design system v2 (restored 2026-11-11): lucide icons, Fraunces/Cormorant/Inter type, blue accent, rounded surfaces — with the `/shopping` console layout (status strip, stage readout, ranked ledger) retained on the original cream/coral palette.

## Core Features

### Editorial Publication
- **10 niches** (`lib/niches.ts`, slugs immutable): AI Tools, Programming, Android, Windows, Gadgets, Gaming, Career, Finance, Productivity, PC Hardware
- Article pages with table of contents, code syntax highlighting, niche-specific editorial treatments
- Reading progress bar, related posts, ambient niche color wash
- Cinematic hero for Gaming niche

### Personal Knowledge Space (Library)
- **Saved** — bookmarked articles
- **Reading Queue** — intentionally saved for later
- **History** — previously read content (auto-recorded)
- **Highlights** — saved text selections with optional private notes
- **Private Notes** — user notes on articles (never public)
- **Collections** — named groups of saved posts (create/rename/delete)

### Creator / Community Platform
- **Public profiles** (`/profile/@username`) — avatar, bio, links, interests, published articles
- **Author following** — follow writers, see their posts on homepage
- **Topic following** — follow niches, personalized discovery
- **Comments** — article discussions with ownership enforcement
- **Onboarding** — 3-step flow (name → username → interests)
- **Article editor** — markdown, niche selection, cover image, SEO fields

### Shopping Intelligence (100% live AI)
- **Live product data** — search, detail, and compare results are generated by Gemini **at request time** through the central AI router (`lib/ai-router.ts`: 3.8-flash → 3.7-flash → 3.6-flash, then Groq fallback). No offline catalog.
- **AI-estimated prices** — INR estimates, always labeled, with Amazon.in / Flipkart search links for verification
- **AI shopping assistant** (`/shopping`) — natural-language picks with reasoning and buy links
- **AI PC builder** (`/pc-builder`) — budget + use-case builds with component reasoning
- **Product comparison** (`/compare`) — side-by-side specs, per-row winners, verdict
- **Buying guides** — editorial guides with structured recommendations (Supabase)

### Admin Dashboard
- Single admin account, full CRUD over all posts
- AI draft generation (Gemini via the central AI router; drafts never auto-publish)
- Image upload, niche-aware publish button

## Tech Stack
- **Framework**: Next.js 15 (App Router, Turbopack dev), React 19, TypeScript
- **Database**: Supabase (PostgreSQL + Auth + Storage; 20 tables — source of truth `website/supabase/schema.sql`)
- **AI**: Gemini (3.8/3.7/3.6-flash chain) with Groq fallback — one chokepoint, `lib/ai-router.ts`
- **Styling**: Tailwind CSS, self-hosted variable fonts (Fraunces, Cormorant Garamond, Inter, JetBrains Mono) + Pixels brand font
- **Auth**: Two systems — admin (custom JWT cookie) + users (Supabase Auth with RLS)
- **Email**: Resend (contact form)
- **Icons**: lucide-react
- **Markdown**: react-markdown + remark-gfm + rehype-highlight + rehype-slug
- **Analytics**: Vercel Speed Insights (Vercel-gated) + Vercel Web Analytics

## Environment Variables
Required in `website/.env.local` (full reference: `website/.env.example` + `website/docs/environment.md`):
```env
NEXT_PUBLIC_SUPABASE_URL=...
NEXT_PUBLIC_SUPABASE_ANON_KEY=...
SUPABASE_SERVICE_ROLE_KEY=...
ADMIN_SESSION_SECRET=...          # random 32+ char string
ADMIN_EMAIL=admin@example.com
ADMIN_PASSWORD_HASH_B64=...       # bcrypt hash, base64-encoded (run: npm run hash-password)
GEMINI_API_KEY=...                # products / shopping / pc-builder / admin drafts
GROQ_API_KEY=...                  # optional: fallback AI pool (separate quota)
RESEND_API_KEY=...                # optional: contact form email
NEXT_PUBLIC_SITE_URL=...          # canonical URL (metadata, sitemap)
```

## Database Setup
1. Create Supabase project
2. Run `website/supabase/schema.sql` in SQL Editor (idempotent, safe to re-run — 20 tables, the current source of truth)
3. Add `localhost:3000` and production URL to Supabase Auth → URL Configuration → Redirect URLs
4. Enable Email provider in Supabase Auth
5. Configure `.env.local` with project credentials

See `Guides/01-database-setup.md` for full walkthrough.
