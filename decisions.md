- **2026-11-09 — Silkscreen redesign (website/CHANGELOG 1.4.0):** design system v3 built with the awwwards-skill workflow (github.com/juliobsz/skills — note: that repo has no `/shopping` skill; only `/awwwards` and `/jury`; "especially /shopping" was interpreted as focus on our `/shopping` route). Decisions:
  - **Icons — hand-drawn sharp-flat, not licensed Streamline.** Owner asked for streamlinehq.com sharp-flat icons; the official npm package requires a paid subscription + secret token. Chose to hand-draw 69 glyphs in the same visual language (fills only, sharp corners, two-tone via `currentColor` + 34 % tint) with lucide-compatible names/API — zero licensing risk, full token integration. Alternative rejected: subscribing and vendoring SVGs (cost, license constraints, no dynamic theming).
  - **Typography — Archivo Variable (one family, two cuts), serifs removed.** Fraunces + Cormorant + Inter were the exact "reflexive generator choices" the skill warns against. Archivo's width axis gives a heavy Expanded display cut and a normal text cut in one self-hosted file (skill-endorsed pairing). JetBrains Mono retained as the data voice.
  - **Radius 0 sitewide via Tailwind scale override** rather than editing ~160 call sites — reversible, keeps `rounded-full` semantics for true circles. Avatars and pills squared deliberately (PCB-pad look); niche color dots, orbit rings and the spinner stay circular (geometry, not corner radius).
  - **Accent blue → signal red-orange** (AA-verified per role): unifies the site with /shopping's red, reads as calibration/signal on the instrument-panel concept; blue was also the near-default choice.
  - **/shopping rebuilt as a console** (scanline signature, stage readout, ranked ledger) on site tokens — its previous hardcoded cream/teal palette was flagged in docs as inconsistent and is gone.
  - `website/DESIGN.md` added as the awwwards-skill planning artifact (concept card, system, kept-brand notes).
